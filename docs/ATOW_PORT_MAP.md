# A Time of War - port map

Source of truth for porting *A Time of War* (ATOW, `ScenarioId.TimeOfWar`) to the web app, one task per section 2.x.
Conventions are in `CLAUDE.md` (windows/popups/hubs, `SaveToUndo`, `RandomArray` vs `Flavor`, mirror mode, CSV rules) and
the checklist in `PLAYTEST_FINDINGS.md`. Fear of the Unknown (`Shared/Scenarios/FearOfTheUnknown/`) is the reference
for structure and granularity.

Read a passage: `python tools/cradle_dump.py ATimeOfWar.txt <Passage> [--html]` (CSV-ready text with `--html`).
Passage names below are the Twine names (exact, case-sensitive).

## 0. Source files and which one is authoritative

| File | What it is |
|---|---|
| `MyFathersWorkConsole/MyFathersWorkConsole/Processor/ATimeOfWar.txt` | Decompiled Cradle class from the shipped app. 297 passages. |
| `UnityOriginalApp/Assets/Scripts/StoryScript/English/ATimeofWarEng.cs` | Unity source, generated by Cradle 2.0.2.0 from `ATimeofWarVer8.html`. 300 passage blocks, 3 of them commented out (`ResistStick`, `THEBIGREDBUTTON`, `ReignEndings`). |

Compared passage by passage (normalized for decompiler syntax): **the story content is identical** - same text,
links, conditions, variables, `either`/`random` calls and setup images. The only differences:
- decompiler noise (`goToPassage:`, `?.Invoke`, string splits, `random(1.0, 5.0)` vs `random(1, 5)`, `else if` vs nested if);
- the `.cs` has the bold "SETUP"/"SPECIAL SETUP" headers inside setup blocks commented out (`//yield return text("SETUP")`);
  the `.txt` prints them. Cosmetic - the web popup title already says Setup/Special Setup;
- `Reign7c` title input: `.txt` content type `"string"`, `.cs` `"password"` (Unity input-field type only);
- `Rumor6TimeRes` (unreachable) has an inverted condition.

Neither file is clearly newer; both are "Ver8". **Use `ATimeOfWar.txt` (via `cradle_dump.py`) as the text source.**
English only (`English_Source` column). Voice-over clips exist in Unity for 11 ATOW passages
(`docs/AUDIO_TRANSITIONS_MAP.md` section 8, "Not ported") - out of scope for the port tasks, `SetVoiceOver` can be added later.

## 1. Overview

### 1.1 Generations and branches

```
ATOW-Preparations -> ForewordScen2 -> ATimeofWarIntro (Gen I "Taking Sides") -> IntroConflict -> TakingSides hub x3
   end of Gen I: $war == 2 -> TowardsWar -> Gen II "Martial"  (IntroMartial-Monarchists "Plagued by Conflict" if Gen I $warwinner == Unified Monarchists,
                                                                IntroMartial-Separatists "Down with the Monarchy" otherwise)
                 $war == 1 -> Warwarn -> TowardsDev -> Gen II "Time Travel" (TimeTravelintro1 "A Return to Devastation")
   end of Gen II Martial (ResistEnd / ResistEnd2 / ResistEnd3, random which one):
        Unified Monarchists win the war  -> MonarchReignIntro  Gen III "Heavy is the Crown"   -> endings 5 / 6
        Separatists win the war          -> PeaceIntro         Gen III "Peace Through War"     -> endings 7 / 8
   end of Gen II Time Travel (TimeEnd1 / TimeEnd2, random which one):
        timeline altered                 -> WarningIntro       Gen III "Future Consequences"  -> endings 3 / 4
        timeline normal                  -> Paradoxical -> ParadoxIntro Gen III "You Cant Stop Progress" -> endings 1 / 2
```

How each branch is chosen:

| Decision | Source | Kind | Web app |
|---|---|---|---|
| Gen I faction the town supports (`$warwinner`, `$warloser`, `$crest`, `$figure`) | `either("Separatists","Unified Monarchists")` in `ATimeofWarIntro` | random | `_RND_WAR_WINNER`, drawn on `IntroConflict` (first screen that shows it) |
| Gen II branch (`$war`: 1 Time Travel, 2 Martial) | `either(1, 2)` in `ATimeofWarIntro`; town name easter egg: `"Paradox"` forces 1, `"Destruction"` forces 2 (applied in `TakeSides3`/`SeedGUNS`/`TSBarracksPenalty`) | random (+ town name) | `_RND_WAR`, drawn lazily on first use (see 4.1). Keep the town-name override, applied where `War()` is read at the end of Gen I. |
| Gen III after Martial | which of `ResistEnd`/`ResistEnd2`/`ResistEnd3` (random, `$iou == 1` forces `ResistEnd`), then a player answer or `$wardestroy >= $wardetermine` | random + player input | `_RND_RESIST_END`; the war winner decides Reign (Monarchists) vs Peace (Separatists) |
| Gen III after Time Travel | `TimeEnd1` vs `TimeEnd2` (random); `TimeEnd1`: players compare Paradox tokens with `$dox`; `TimeEnd2`: Time Machine repaired -> Paradox, else Warning | random + player input | `_RND_TIME_END`, `_RND_DOX` |
| Ending | see section 8 | state + player input | `Vars.Ending` 1-8 |

Unity "round" numbers in the source (`$round`): 1-3 Taking Sides, 4-6 Time Travel, 7-9 Martial, 10-12 Paradox,
13-15 Warning, 16-18 Reign, 19-21 Peace. **Do not store `$round`**; use `HubId` + `globalData.Years`.

### 1.2 Hubs and round structure

One hub method per branch, sections switched by `globalData.Years` and state (FotU pattern). `HubId` enum
`ATimeOfWarHubId { None, TakingSides, Martial, TimeTravel, MonarchReign, Peace, Warning, Paradox }`.

| Hub method | Source hubs | Early -> Middle | Middle -> Late | Late -> end |
|---|---|---|---|---|
| `TakingSides` | `TakeSides`, `TakeSides2`, `TakeSides3` | end-of-round popup -> `TownHallSpecial` (Town Hall meeting, each player) -> hub | end-of-round popup -> `TakeEvent` (Barracks vote) -> `TakingSidesLateSetup` -> hub | end-of-round popup -> `SeedGUNS` / `TSBarracksPenalty` / `Warwarn` / `TowardsWar` |
| `Martial` | `Martial1`, `Martial2`, `Martial3` | **Special Setup popup "do NOT perform End of Round"** -> sabotage/messenger/duel events (still Early) -> `Martia1Pre2` = end-of-round popup -> `MartialMiddleSetup` -> hub | same idea: Special Setup popup -> messenger/tea/sabotage/quartering events -> `MartialPre3` = end-of-round popup -> `MartialLateSetup` -> hub | end-of-round popup -> `BarracksSimple3` -> `ResistSides` -> `ResistEnd*` |
| `TimeTravel` | `TimeTravel`, `TimeTravel2`, `TimeTravel3` | end-of-round popup -> `FixIt` -> (`Militarytoken`) -> hub | end-of-round popup -> `TownHallOpposite` -> `SeedResolution` -> Blame game -> `TimeTravelLateSetup` -> hub | end-of-round popup -> `BlameOut3` or `SecretParadoxBonus` -> `TTBarracksPenalty` -> `TimeEnd1`/`TimeEnd2` |
| `MonarchReign` | `MonarchReign1/2/3` | end-of-round popup -> `Stickfun` (if wooden figures) -> `CoWEvent` vote/bid -> hub | end-of-round popup -> `CommemorativeStatueEvent` (if decrees >= trigger) or hub | end-of-round popup -> `Weapons` -> `ShadowBonus` -> `BenevolenceBonus` -> `Scoring` |
| `Peace` | `Peace1/2/3` | end-of-round popup -> Famine vote/bid -> `PeaceStick` -> `BattleTime` -> `BattleCompleteReturn` -> `PeaceRoundSetup` -> hub | end-of-round popup -> `PeaceEvent` gas vote -> `BattleTime` -> `BattleCompleteReturn` -> `PeaceRoundSetup` -> hub | end-of-round popup -> `FinalBattleTime` -> `FinalBattleComplete` -> `Scoring` |
| `Warning` | `Warning1`, `Warning2`, `Warning3`, `Warning2time`, `Warning3time` | end-of-round popup -> `WarningEvent` -> `TimeWarp1st` -> `WarningMaybe` -> `WarningWorldSetup` -> hub | end-of-round popup -> `TimeWarp2` -> (`OldManToken`) -> setup -> hub | end-of-round popup -> `Scoring` |
| `Paradox` | `Paradox1`, `Paradox2`, `Paradox3`, `Paradox3b` | end-of-round popup -> `ParadoxFirst` -> (`CostStick1`/`FutureStick`) -> Monument vote -> hub | end-of-round popup -> `ParadoxRandoEvent` (if any player released the schematics) -> `ParadoxTimeRandom` -> hub; else hub | end-of-round popup -> `ParadoxGiantCheck` -> `ParadoxEvent` -> `Scoring` |

Rules that matter for all hubs (from `CLAUDE.md` / `PLAYTEST_FINDINGS.md`):
- `ShowEndOfRoundPopUp(next)` advances `Years` (and `Generation` after Late) **before** `next` runs. After the Gen I/II Late
  popup `ActiveHub` is null, so the chain must end in a window/popup/hub, never `_ => { }`.
- After the Gen III Late popup `Generation` is 3 (outside the enum); use an `EndedYears()` guard like FotU if code needs the ended round.
- Martial is the exception to "end of round = popup first": the source shows a *Special Setup* popup saying not to perform the
  End of Round yet, plays the events with `Years` unchanged, and only then shows the end-of-round popup (`Martia1Pre2`,
  `MartialPre3`). Port it exactly that way: `Martial` end section -> `MartialEndOfRound_0` (SpecialSetup popup) -> events ->
  `globalData.ShowEndOfRoundPopUp(MartialMiddleSetup)`.
- Source hubs contain `setupStyle` blocks that Unity shows as a popup whenever the hub is (re)entered, guarded by flags
  (`$pg13`, `$martial`, `$gen3pg`, `$pea1`, `$master`, ...) that only exist to stop the popup reappearing after a sub-screen.
  In the web app show these as **setup popups before the hub at round entry** (FotU `WitchHuntSetup`), and drop the guard flags.
- Hub methods must be side-effect free and draw only for shown sections (guard random text with the section's condition).

Table columns: **Passage** (Twine) | **Method** (proposed C#; `_0` = its setup popup) and kind | **Flow / conditions** |

ready, click here to reveal your secret conversation" in one passage: port as a window `X` (hand-over text +
`AddOnceYouAreReady(XRevealed)`) and a window `XRevealed` (the conversation).

`AddClickHereAfterVote(next)` / `AddClickHereAfterBid(next)` (section 5).

Maladjustment gained at the end of Gen III, and (Time Travel path with the Time Machine Masterwork) -5VP if it was not
completed. Branch-specific end bonuses happen before `Scoring` in their own passages: Reign `Weapons` (1VP per Weapon
token if "restrict"), `ShadowBonus` (6VP closest to the Crown), `BenevolenceBonus` ({decbon}VP); Peace
`FinalBattleComplete` (Weapon tokens -> VP or Vanity Upgrade); Paradox `ParadoxEvent` (In Memoriam). The web app only
displays these; players apply them before entering scores.
